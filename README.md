# CS13 .NET 9 Projects

A collection of C# and .NET 9 projects covering various programming concepts and frameworks.

## Project Structure

- **Chapter01-vsode**: Introduction and basic console applications
  - AboutMyEnviroment: Environment information app
  - HelloCS: Basic Hello World program

- **Chapter02**: ASP.NET Razor and web applications
  - ProfileWebApp: Web application with Angular client
  - Vocabulary: Vocabulary learning application

- **Chapter03**: Arrays, loops, operators, and selection statements
  - Arrays: Array operations
  - CastingConverting: Type casting and conversion
  - FizzBuzzGame: Classic FizzBuzz game
  - IterrationStatements: Loop demonstrations
  - Operators: Operator usage examples
  - SelectionStatements: Conditional logic

- **Chapter04**: Functions, debugging, and unit testing
  - CalculatorLib: Calculator library
  - CalculatorLibUnitTests: Unit tests for calculator
  - Debugging: Debugging techniques
  - TopLevelFunctions: Top-level statement functions
  - WritingFunctions: Function definitions

- **Chapter05**: Object-oriented programming
  - PacktLibraryModern: Modern OOP library
  - PacktLibraryNet2: .NET 2 style library with classes
  - PeopleApp: People management application

## Getting Started

1. Open the solution file (.sln) in Visual Studio or VS Code
2. Restore NuGet packages
3. Build and run the projects
